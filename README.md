# 芳香烃四类通关游戏 V3.5

本版以 V3.4 的芳香烃知识内容与防剧透答题区为基础，按最新课堂交付要求补齐 QuickForm 阶段成绩收集、离线兜底和教师端多来源合并。游戏仍是单文件 HTML，可在手机、电脑和断网环境运行。

## 文件

- `芳香烃四类通关游戏_V3.5.html`：学生端单文件游戏。
- `芳香烃四类通关游戏_V3.5_教师解析器.html`：教师端离线解析器。
- `芳香烃四类通关游戏_V3.5_GitHub_Pages发布包.zip`：可直接用于 GitHub Pages 的发布包。
- `验收报告_V3.5.md`：自动验收结果和上线前人工检查项。

## 四关结构

| 关卡 | 核心任务 | 分值 |
|---|---|---:|
| 1. 命名侦探 | 甲苯、乙苯和二甲苯位置命名 | 20 |
| 2. 结构简式工厂 | 连接方式、分子式、明确环位的结构简式 | 25 |
| 3. 异构体工坊 | 单苯环 C₈H₁₀ 的筛选、旋转、反向编号与去重 | 25 |
| 4. 证据鉴别实验室 | 结合侧链、模型条件和证据边界作结论 | 30 |

共 13 个正式任务、100 分。正式题完整提交后才计一次尝试；答错不扣分，但会在关尾生成必修新题变式。未完成本关全部错题变式，下一关、最终成绩单和打印均不会解锁。

## V3.5 重新设计要点

1. 保留 V3.4 对 S3、S4 的防剧透修正。结构简式输入框旁只说明“应唯一对应已确认环位”，不会提前给出 `1,3-`、`1,4-`、`m-` 或 `p-` 答案形式。
2. 每关真正完成后出现一个 QuickForm 检查点，最多 S1—S4 四条；后一关记录包含此前累计进度，通常只收最终 S4 即可。
3. QuickForm 完全自愿：学生必须核对身份、勾选同意并点击提交。页面不自动上传、不自动重试，断网或服务器失败不会影响答题、得分或本机存档。
4. 使用稳定提交键 `训练编号-S1` 至 `训练编号-S4`。成功或服务器排队后，本机保存回执并阻止同阶段重复提交；超时只提示“结果可能未知”。
5. 正常 JSON 大小超过 60,000 字节时禁止联网发送，改用 CSV；QuickForm 不可用时仍可交 ARO35 短码或固定 20 列 CSV。
6. 教师解析器 V1.4 可同时导入 QuickForm `/all` JSON、`submissions.json`、ARO30—ARO35 短码与 AROCSV32—AROCSV35 CSV。它先按提交键保留较新记录，再按训练编号选取进度最完整的一条，并合并多来源身份和轨迹。
7. 本地存档协议升至 `aromatic-3.5-r1`。首次打开 V3.5 时，可保留 V3.4 的四关进度、分数和事件；旧键不删除。

## QuickForm 配置与数据边界

学生端配置的成绩收集地址为：

`https://quickform.cn/api/d36lmyvekx`

提交内容包括班级、姓名、10 位学号、训练编号、成绩、分关得分与尝试、活动用时、提示/错题、完成状态、详细学习短码和校验值。地址会出现在前端源码中，不应把它当密码或正式考试认证手段，也不要在载荷中加入账号、口令或其他无关敏感信息。

QuickForm 记录协议为 `AROQF35`，详细短码为 `ARO35`。服务器可能返回 HTTP 200（成功）或 202（已排队）；两种情况都会生成本机回执。HTTP 失败或等待超时不会清空学习记录。

若 240 名学生每关都提交，最多约 960 条记录；若只收四关最终 S4，约 240 条记录。课堂上可按实际需要要求学生只提交最终成绩。

## 教师端使用

1. 从 QuickForm 下载或复制 `/all` JSON；也可收集学生的短码或 CSV。
2. 双击打开教师解析器，无需联网。
3. 粘贴 JSON/短码，或多选 JSON、CSV 文件。
4. 点击“解析全部记录”。同一提交键自动去重，同一训练编号自动合并。
5. 查看任务汇总与操作时间线，必要时导出汇总 CSV 或详细轨迹 CSV。

## GitHub Pages 覆盖发布

1. 解压 `芳香烃四类通关游戏_V3.5_GitHub_Pages发布包.zip`。
2. 用包内文件覆盖仓库根目录；学生入口为 `index.html`，教师工具为 `teacher-parser.html`。
3. 提交并推送到当前 GitHub Pages 分支。
4. 发布后用手机和电脑各打开一次，确认页面标题显示 V3.5，旧 V3.4 存档能继续，且真实 QuickForm 测试记录能被教师解析器导入。

## 上线前必须人工确认

- 在任课教师控制下提交一条真实测试记录，确认 QuickForm 后台字段和 JSON 导出格式。
- 在校园网、手机流量各测试一次成功、失败和超时提示。
- 用常见手机宽度检查输入、环位按钮和提交区没有横向溢出。
- 完成一次完整错题路径，确认关尾变式、下一关解锁和最终 S4 提交顺序。
- 打印或另存为 A4 PDF，确认成绩单为一页且包含红色总分和“错题变式已全部完成”。
