# 芳香烃四类通关游戏 V3.6

学生端和教师端都是可离线打开的单文件 HTML。四关共 13 个正式任务、100 分；答错后须完成关尾错题变式，才能解锁下一关与最终成绩单。

| 关卡 | 内容 | 分值 |
|---|---|---:|
| 1. 命名侦探 | 从结构卡判断母体、侧链和环位，写出名称 | 20 |
| 2. 结构简式工厂 | 选择连接方式、分子式，写明确位置的结构简式 | 25 |
| 3. 异构体工坊 | 单苯环 C₈H₁₀ 筛选、旋转编号与去重 | 25 |
| 4. 证据鉴别实验室 | 比较虚拟观察、条件和结论边界 | 30 |

## 本次修正

1. 第一关前四张标签的标题改为中性说明。标签一、二的结构图下只显示“结构卡”和“观察环外连接”，不先写甲苯、乙苯或基团名称；标签一第二步 A/B/C 只显示乙基、甲基、乙烯基，不在选项后附结构式。题面保留作为判读依据的结构图。结构简式工厂前两题也不再附上直接给出正确结构的示范图。
2. 间、对二甲苯统一按“正确位置前缀 × 三种明确的结构简式写法”判题。`1,3-(CH3)2C6H4`、`1,3-C6H4(CH3)2`、`m-CH3C6H4CH3` 等间位写法及相应对位写法均接受。普通数字、下标、全角逗号和可选单键短线统一处理。错误环位、裸式 `C6H4(CH3)2`、仅写 `C8H10` 仍判错；甲苯、乙苯的简式也接受单键分隔写法。
3. 自愿提交的 QuickForm 地址改为 `https://quickform.cn/api/cs3jd21zqw`。每关清空后可主动提交阶段记录，必须核对身份、勾选同意并点击；没有自动上传或自动重试。网络失败不会清空本机存档。
4. 学生端升级为 `aromatic-3.6-r1`、`ARO36` 短码、`AROCSV36` 的 20 列 CSV、`AROQF36` 联网记录。教师解析器 V1.5 同时读取新旧 QuickForm JSON、ARO30—ARO36 短码与 V3.2—V3.6 CSV，按提交键去重、按训练编号合并。
5. 首次打开新版时，可迁移 V3.5 或更早兼容版本的进度、分数、事件和错题状态，旧存档原样保留。旧 QuickForm 地址的回执留在旧存档，不阻止学生向新地址自愿提交。

## 文件与发布

- `芳香烃四类通关游戏_V3.6.html`：学生端，双击即可离线打开。
- `芳香烃四类通关游戏_V3.6_教师解析器.html`：教师端，离线导入 QuickForm JSON、短码或 CSV。
- `芳香烃四类通关游戏_V3.6_GitHub_Pages发布包.zip`：含 `index.html`、`teacher-parser.html`、本说明和验收报告，可解压覆盖现有 GitHub Pages 仓库根目录。
- `验收报告_V3.6.md`：已执行的自动验收及仍需在实际教学环境核对的项目。

发布到同一站点与路径时，浏览器的旧版 localStorage 才能被新版自动读取。更换域名或路径后请先导出旧记录；旧文件不会被新版主动删除。

## 学习记录与教师端

联网载荷包含班级、姓名、10 位学号、训练编号、成绩、关卡进度、活动用时、提示和错题信息，以及详细学习短码。只有学生主动提交才发送。成功或服务器排队后本机记录回执；超时提示结果可能未知。短码和 CSV 可用于人工补交，也含身份与逐次学习轨迹，应只交任课教师。

教师可将 QuickForm `/all` JSON 粘贴到解析器，或导入 JSON、CSV 文件。按“解析全部记录”查看汇总与逐次操作，再导出教师用汇总和详细 CSV。校验码只用于检查普通复制损坏，不能证明记录未经修改。

## 上线核对

本地自动测试使用 `node test_v3_6.js`，覆盖判题正反例、完整通关、错题变式、旧档迁移、模拟 HTTP 200/202/503 和教师端新旧记录合并。未向真实 QuickForm 写入测试数据。正式使用前，在教师控制下提交一条测试记录并导出后台 JSON 核对字段；再在手机上确认结构卡和选项的显示、输入框、环位操作以及 A4 打印。
