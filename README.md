# 芳香烃四类通关游戏 V2.1

面向学生的单文件网页游戏。四关各 25 分，共 12 项、100 分；不需要服务器、账号、构建工具或第三方资源。学生可在 GitHub Pages 链接上直接打开，也可离线打开 `index.html`。

| 关卡 | 学习任务 |
| --- | --- |
| 命名侦探 | 识别甲苯、乙苯和邻/间/对二甲苯 |
| 结构简式工厂 | 在苯环上拼接侧链，并写出明确位次的结构简式 |
| 异构体工坊 | 从 C₈H₁₀ 候选中筛选、去重，列齐四类单苯环烃 |
| 鉴别实验室 | 读取虚拟 KMnO₄ 观察记录，在给定候选中谨慎结案 |

## 上传到 GitHub Pages

1. 将此目录中的 `index.html` 放在 GitHub 仓库 `main` 分支根目录。`README.md` 与 `logic-check.mjs` 可一并保留；无需上传 ZIP 本身。
2. 在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存。
3. 等 GitHub 显示发布链接后，用学生设备打开该链接实际试做。仓库的 Pages 入口必须是根目录的 `index.html`。

若已有课程仓库，可只替换其发布目录中的 `index.html`。请不要在课堂进行中替换版本：V2.1 使用独立存档，旧版本进度不会自动迁移。

## 第 2 关判题说明

对二甲苯必须同时满足：环上两个甲基相对；文字简式明确标出对位。支持普通数字、下标、空格及常见连接短线。

| 输入示例 | 判定 |
| --- | --- |
| `1,4-C6H4(CH3)2`、`1,4-C₆H₄(CH₃)₂` | 对位，接受 |
| `p-CH3C6H4CH3`、`对-C6H4(CH3)2` | 对位，接受 |
| `C6H4(CH3)2` | 未说明两个甲基的位置，提示补写位次 |
| `1,2-C6H4(CH3)2`、`m-C6H4(CH3)2` | 邻位或间位，与对位任务不符 |
| `C8H10` | 仅为分子式，不能代替结构简式 |

正式题完整提交才计尝试；答错不扣分，但每项错题须在所有正式题结束后重练通过。成绩单在待练清零后开放，可用浏览器打印或存为 PDF。每项首次通过会显示徽章并尝试播放语音；声音可关闭。

## 记录与课堂使用

- 身份、草稿、正式尝试、错题和成绩保存在当前浏览器的本地存储。刷新可续做；换设备、换浏览器、无痕模式或清除网站数据后不能自动找回。
- GitHub Pages 只发布静态网页，不收集全班成绩。教师需要学生提交成绩单 PDF 或按课堂流程展示；客户端记录可以被本机用户修改，不应当作防篡改考试凭证。
- 本页化学实验是给定候选条件下的教学模型，不代替实物鉴定。苯及氧化剂等实物由专业人员按实验室规范管理，不用气味鉴别。
- 从 V2.0 升级时，本版使用新存储键和 `AR21-` 记录编号，不覆盖旧版记录。
